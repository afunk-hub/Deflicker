What this tool can—and can't—do

  • Exposure deflicker: uses FFmpeg's temporal deflicker filter to reduce abrupt frame-luminance variations.
  • Color: exposure correction may reduce some perceived color pumping, but it cannot perfectly reconstruct changing white balance. Optional temporal blending is experimental and can cause ghosting.
  • Natural sunrise: gradual brightness changes are intentional. Review the result to make sure the sunrise hasn't been flattened.
  • Big files: the app does not impose a 200 MB upload cap, but the browser engine keeps working data in device memory. A 500 MB input is not guaranteed to process on every phone.
